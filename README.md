# 🔴 picoCTF Red Team Writeups

Welcome to my collection of **picoCTF writeups**, focused on **red team techniques** and offensive cybersecurity practices.

## 📌 About This Repository

This repository contains my personal writeups for challenges from [picoCTF](https://picoctf.org/), one of the most popular beginner-friendly Capture The Flag (CTF) platforms.

All writeups are part of my journey in learning **ethical hacking**, with a strong focus on understanding how attackers think and operate.

## 🎯 Purpose

This repository is created to:
- Document my progress in cybersecurity
- Strengthen my problem-solving and exploitation skills
- Share knowledge with others interested in CTFs and red teaming
- Provide a reference for beginners and learners
