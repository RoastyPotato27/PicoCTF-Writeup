**2. Recon**  

**What is SymLink?**

>A **symlink** (symbolic link) is a special file that points to another file or directory, acting like a shortcut to it.

>NOTE: The primary mechanism behind privilege escalation via symbolic links is the ability to bypass file permissions. When an attacker has access to a low-privileged account, they may not be able to modify or read sensitive files that are protected by access control policies. But, by creating a symlink, they can point to a protected file and potentially escalate their privileges.
>You cannot create/overwrite an existing file. It must be new.
