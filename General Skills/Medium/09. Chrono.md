So we log in to the server via ssh 

`ssh picoplayer@saturn.picoctf.net -p <port>`

These are where cronjob's exist

User crontab -	/var/spool/cron/
System crontab -	/etc/crontab
Package cron jobs -	/etc/cron.d/
Daily scripts	- /etc/cron.daily/
