**2. Exploit**  

First we connect to the server ssh command provided in the desc. of the challenge.

I have no words for how annoying this challenge was....

It capitalizes first letter of everything you give it, although there were some weird ones where it changed the input
entirely, like `env` command was changed to `End`, among many other.

So, I first spent a while trying random commands in hope that one will work (they didn't)

Then I went to GTFOBins to see if they had a way, tried those too (it didn't work)

Then in the `env` command it printed `End` so I searched around that, and completely wasted my time....

Even bugged out the python file a few times that was used to create the challenge, hoping that maybe that will help, but am too dumb for that.

Then after giving up and questioning my life choises, a writeup talked about something called **Parameter Expansions (in bash)**

So, after regaining some hope I went ahead and learned about it!

...it's quite powerful.... I recommend you also go and learn about it, it will be of great help in your career.

Anyways, back to the ctf, the syntax for using parameter expansion is `${var_name='<your command here>}`

Using that syntax I could finally move!
