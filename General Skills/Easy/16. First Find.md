**Title:** First Find

**Difficulty:** Easy

**Summary (TL;DR):**

using grep to find a hien file. 

`grep -rl picoCTF{`

**1. Scope & Setup**

**Target:** --

**Environment:** Local System, pico VM

**Tools used:** Terminal

**2. Recon**

Download and unzip the file. You will see a directory with a lot of directories in it, No need to go through them one by one. 

Just use `grep -rl picoCTF` 

-r is for recursive search (will search in every directory inside the main directory.

-l only prints the path

**3. Flag**

`picoCTF{f1nd_15_f457_ab443fd1}`
