**Title:** First Grep

**Difficulty:** Easy

**Summary (TL;DR):**

Using grep and regex to sort through a list of string.

**1. Scope & Setup**

**Target:** --

**Environment:** Local System, picoVM

**Tools used:** Terminal

**2. Exploit**

If we use the regular grep command, we get a giant mess which you CANN watch out for the red colored text, but 
why do it when we have a better way?

We can use "regular expressions" to sort through the output. 

`grep -o picoCTF{[^}]*} path/to/file`

**How it works:**

* -o → print only the match

* picoCTF{ → match literal start

* [^}]* → match everything that is NOT } (any length)

* } → stop at the first closing brace
