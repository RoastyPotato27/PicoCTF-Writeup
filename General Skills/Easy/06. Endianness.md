**2. Recon**

> What the hell even is Endianness?
>
> Endianness refers to the byte order used to represent data in memory. It determines how multi-byte data (like integers) is stored:
>
>* **Big-endian**: Most significant byte (MSB) is stored first (at the lowest memory address).
>* **Little-endian**: Least significant byte (LSB) is stored first.
>
>For example, the 4-byte number `0x12345678` would be stored as `12 34 56 78` in big-endian and as `78 56 34 12` in little-endian.
