**2. Recon**

* **Binary**: a number system using only **0 and 1** (base-2); computers use it to represent data.
* **Bitwise operations**: act on individual bits of binary numbers.
* **Common ops**: **AND (&)** → 1 if both bits are 1; **OR (|)** → 1 if either is 1; **XOR (^)** → 1 if bits differ; **NOT (~)** → flips bits; **shifts (<<, >>)** → move bits left/right.
* **How to perform**: line up the binary numbers and apply the rule **bit by bit**.
